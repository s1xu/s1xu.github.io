## 背景

书房路由器坏了，本来想直接换一个了事，检查了一下发现这台路由器最大只支持 20Mbps 带宽。家里电信宽带是 1000M，等于一直在用 2% 的速度上网，属实浪费了。

客厅已经有一台中兴 E1600（电信定制版）千兆路由，负责 IPTV 和全屋设备联网，运行稳定没什么问题。既然书房要换路由，不如趁机做个 Mesh 组网，全屋统一管理。

## 设备选择

Mesh 组网需要同品牌路由器配对。客厅已有中兴 E1600，所以新购了一台中兴 AX3000 巡天款作为主路由，E1600 降级为 Mesh 子节点。

| 设备 | 角色 | 位置 |
| --- | --- | --- |
| 中兴 AX3000 巡天款 | 主路由 | 弱电箱旁 |
| 中兴 E1600 电信定制 | Mesh 子节点 | 客厅 |

## 原有拓扑

之前是光猫分别走墙内网线到客厅和书房，各自独立连接，两个路由各管各的。

```
                        ┌──── 墙内网线 ────→ [客厅路由 E1600] ──→ IPTV / 各设备
[入户光猫] LAN ─────────┤
                        └──── 墙内网线 ────→ [书房路由(20M)] ──→ 书房设备
```

问题很明显：
- 书房路由带宽只有 20Mbps，严重瓶颈
- 两个路由各自为政，不在同一网段，设备互访不便
- 光猫直接分出两条线，没有统一的路由管理

## 现有拓扑

AX3000 作为主路由接在光猫后面，统一管理所有出口。客厅 E1600 通过有线回程做 Mesh 子节点，IPTV 接在 E1600 的 LAN3 口。

```
[入户光猫] LAN
     │
     ▼
[AX3000 巡天款] WAN ← 主路由（光猫拨号，路由模式桥接）
     │
     │ LAN ──→ 墙内网线 ──→ [客厅 E1600] WAN ← Mesh子节点（有线回程）
     │                            │
     │                            ├── LAN3 ──→ IPTV
     │                            └── WiFi  ──→ 客厅设备
     │
     └── WiFi ──→ 书房设备（无线覆盖）
```

## 效果

- 全屋统一 SSID，设备自动漫游切换，不用手动切 WiFi
- 书房通过 AX3000 无线覆盖，实测带宽从 20Mbps 大幅提升
- IPTV 正常使用，E1600 LAN3 口单独走 IPTV 流量不受影响
- 有线回程延迟低，比无线回程稳定不少
- 书房不再需要单独的路由器和网线，AX3000 无线直接覆盖

## 坑点：IPTV 无网络

Mesh 组网后全屋 SSID 统一，不用再手动切 WiFi 了，但 IPTV 一直显示无网络。

原因是 Mesh 组网改变了网络结构，IPTV 需要通过 VLAN 单独走专用通道才能正常工作。之前 E1600 直连光猫时 IPTV 口直接出信号没问题，现在中间多了一层主路由，IPTV 流量需要通过 VLAN 透传到客厅 E1600。

### 解决步骤

1. 光猫后台设置
   - 进入 网络 → 绑定设置
   - 选择光猫连接 AX3000 的 LAN 口
   - 设置 VLAN ID 为 `45`

2. 主路由 AX3000 设置
   - 开启 IPTV 功能
   - 不使用光猫 IPTV 口
   - VLAN ID 设置为 `45`
   - LAN 口选择连接客厅的网线

3. 客厅 E1600 设置
   - 进入 网络功能 → IPTV
   - 开启 VLAN，专案 ID 设置为 `45`
   - 选择 LAN3 口（即 IPTV 电视接入的口）

三层设备的 VLAN ID 保持一致，设置完成后 IPTV 恢复正常。
